# 《遗迹快跑》资源规范 v1（定稿，2026-10-11 美术已确认）

> 日期：2026-10-11。数字都是程序这边的建议，美术觉得做不到或不好看的地方直接改，确认后定稿，抄送制作人。
> 默认按美术推荐的 **B 风格（粗描边 + 平涂一层阴影）** 写；如果老板选了别的风格，第 4、5 节的帧数和图集预算要重算。

## 1. 设计分辨率与屏幕适配

- **设计分辨率 750 × 1334（竖屏）**。美术所有切图按这个尺寸的 **1 倍**出图（即在 750 宽画布上看到多大就切多大），程序在高分屏上最多放大到 2 倍渲染，不需要另出 @2x/@3x。
- **宽度固定 750，高度随屏幕变长**：9:16 屏幕高度 1334，9:19.5（常见全面屏）约 1624，9:21 约 1750。游戏画面（地图）铺满全部高度；HUD 顶部区贴上边、底栏贴下边，中间是摇杆区，所以长屏只是战斗区更高。
- 比 9:16 更宽的屏幕（平板、折叠屏）：按高度 1334 适配，左右留边，边上用区域底色填充。
- **背景类大图**（加载页、主界面背景、结算底图）请按 **750 × 1750** 出，关键内容放在中间 750 × 1334 范围内，上下多出的部分是"可以被裁掉的延伸"。

## 2. 安全区（刘海屏、挖孔、底部手势条）

- 程序在运行时读平台给的安全区，换算成设计像素后把 HUD 往里推。美术只需要遵守：
  - **顶部**：顶部信息区（暂停、层数、HP、倒计时、撤离按钮）整体放在安全区下方，按 **预留 88px**（约 44pt 刘海）设计，没有刘海的机器程序会自动上移。
  - **底部**：底栏下方预留 **68px**（约 34pt 手势条）。
  - **左右**：所有按钮、文字离左右边 ≥ 24px。
- 底色、地图、背景可以画到安全区外（铺满全屏），但**不能把按钮和文字放进去**。

## 3. 网格、瓦片与房间

- **1 格 = 64 px**（设计像素）。GDD 写的"1 格 ≈ 48px"是参考值；48px 在手机上主角只有约 24pt 宽，B 风格的粗描边会糊，所以建议 64px。屏幕横向能看到约 11.7 格、纵向约 21–27 格。**这个数字会影响所有手感数值（射程、移速、Boss 技能范围），需要策划在灰盒里确认手感**，程序会做成可调。
- 视角：**正俯视偏 3/4（俯视约 45°）**，角色只画朝右，朝左由程序镜像。
- **地面瓦片 64 × 64**，四方连续无缝；每个区域 4–6 种地面 + 2–3 种过渡/点缀瓦片。
- **墙/障碍**：占地按整格（1×1、2×1、2×2 格），图片可以向上超出占地格（表现高度），**占地格范围请在交付时标注**（程序用来做碰撞）。
- **房间模板 18 × 18 格 = 1152 × 1152 px**（约 1.3 个屏幕，对应 GDD "约 1.5 个屏幕"），一层 3×3 块 = 54 × 54 格。房间用瓦片 + 装饰物拼，不出整张大图。每个房间在模板里标出：出生点、宝箱点、陶罐点、撤离点候选（≥ 3 个）、障碍格。房间编辑格式（Tiled .tmj 或 Excel 格子表）程序 M1 前给模板。

## 4. 角色、怪物、Boss 动作（序列帧）

- 动画方案：**序列帧**，基准 **12 帧/秒**。闪白、受击抖动、缩放弹跳、换色由程序做，美术不用出。
- **每个角色所有帧画布尺寸统一**，锚点统一在**脚底中心**（画布底边往上 8px 处），方便程序对位。
- 死亡统一用"冒星星/变烟"通用特效（美术出 1 套，所有普通怪共用），普通怪只需要 2–3 帧"被打飞"过渡。

| 对象 | 画布尺寸 | 动作与帧数 |
|---|---|---|
| 主角 小探险家 | 128 × 128 | 待机 6、跑动 8、受击 2、死亡（坐地哭）10、胜利欢呼 10 |
| 普通怪（史莱姆、蝙蝠、蘑菇射手、宝箱怪、盗宝鼠） | 96 × 96 | 移动 6、攻击/前摇 4–6、死亡过渡 3（宝箱怪多一个"关闭待机 1 + 跳起 6"） |
| 石头小傀儡 | 128 × 128 | 移动 6、蓄力（变红）4、冲撞 4、死亡过渡 3 |
| 小史莱姆（分裂） | 64 × 64 | 复用史莱姆缩小，不用单独出 |
| 精英怪 | 程序放大 1.3 倍 + 金色描边着色器，不用单独出 |
| Boss 咕噜噜 / 喵老大 | 256 × 256 | 待机 8、移动 8、每个技能 8–12、登场 12、死亡 12；立绘 1 张（登场用，≤ 750 × 750） |
| 遗迹守卫 | 192 × 192 | 移动 8 |
| 宝箱 | 96 × 96 | 关闭 1、打开 1、开箱 6 |

- **换色**：B 风格优先由程序按色板换色（美术给每个区域一张色板对照表），换不出来的再单独出图。
- 怪物统一的"红紫色描边光"请直接画进图里（或者给出统一颜色值，程序用着色器加，二选一，美术定）。

## 5. 特效

- 序列帧为主，**每个特效 8–12 帧**（GDD §14.3），画布按实际尺寸裁切，最大不超过 256 × 256。
- 可以循环的特效（花瓣护盾、火焰、光门）请标注循环帧。
- 发光类用"加色混合"效果的，请在命名里加 `_add`，程序用 ADD 混合模式绘制，图上黑底即可。
- 伤害数字、暴击数字：**位图字体（BMFont）**，美术出 0–9、"+"、"-"、"暴击"字样的 PNG，程序打包成字体。

## 6. UI

- 按钮最小点击区 **88 × 88 px**（= 44pt）。
- **底栏背包格**：每行 8 格，格子图 **84 × 84**，间距 6，左右各留 18。84 略小于 88，程序会把点击区扩到格子间距，保证可点。安全格蓝框带锁、背包格普通框，各出 1 张底框 + 选中态 + 不可用态。
- 面板、按钮、进度条用**九宫格**：交付时写明四边不可拉伸的像素（例如 `24,24,24,24`）。
- 图标：技能图标 **128 × 128**（统一边框，GDD §13.2）；宝物、材料、装备图标 **96 × 96**，稀有度底框单独出 5 张（白/绿/蓝/紫/金），程序叠加。
- 字体：只用**可商用授权**字体，交付字体文件 + 授权说明；正文最小 24px（12pt）。

## 7. 图集与文件格式

- 打包工具：**TexturePacker**，导出格式 **Phaser 3（JSON Hash）**，多张时用 multiatlas。
- 单张图集最大 **2048 × 2048**，开 Trim（裁透明边）、Padding 2、Extrude 1。
- 按"一起出现的资源打一张"：`atlas_common`（主角、通用特效、掉落物、BMFont）、`atlas_garden`（花园怪、瓦片、装饰、宝箱）、`atlas_ui_hud`、`atlas_ui_menu` 等。一个区域局内用的图集合计不超过 3 张。
- 图片 PNG（RGBA），提交前用 pngquant 压一遍（程序可以帮忙跑）；以后视性能再转 WebP。
- 源文件（PSD/Aseprite 等）放 `art_src/`，不进游戏包。
- 音频：mp3，BGM 96kbps 立体声、循环无缝；音效 64kbps 单声道、≤ 2 秒。文件名用 GDD §17.5 的 ID（例如 `sfx_hit.mp3`）。

## 8. 命名规则

全部 **小写英文 + 下划线**，不用中文、空格、大写。**ID 和配置表一致**（例如配置表里怪物 ID 是 `mon_slime`，图片就叫 `mon_slime_move_01.png`）。

格式：`类别_对象[_区域]_动作_两位序号.png`

| 类别前缀 | 用途 | 例子 |
|---|---|---|
| `chr_` | 主角 | `chr_player_run_01.png` |
| `mon_` | 普通怪（区域换色版加区域） | `mon_slime_move_01.png`、`mon_slime_shrine_move_01.png` |
| `boss_` | Boss | `boss_vine_golem_skill1_05.png`、`boss_vine_golem_portrait.png` |
| `npc_` | 遗迹守卫等特殊单位 | `npc_guardian_move_01.png` |
| `tile_` | 地面瓦片 | `tile_garden_ground_01.png` |
| `deco_` / `obs_` | 装饰 / 障碍（有碰撞） | `deco_garden_flower_03.png`、`obs_garden_pillar_01.png` |
| `obj_` | 宝箱、陶罐、光门、阶梯 | `obj_chest_wood_open_03.png`、`obj_portal_loop_01.png` |
| `fx_` | 特效（加色混合加 `_add`） | `fx_boomerang_01.png`、`fx_levelup_add_01.png` |
| `icon_` | 图标（技能 ID、宝物 ID 与表一致） | `icon_skill_boomerang.png`、`icon_tr_vine_crown.png` |
| `ui_` | 界面 | `ui_btn_primary_normal.png`、`ui_btn_primary_pressed.png`、`ui_panel_popup.png` |
| `bg_` | 大背景 | `bg_main.png`、`bg_loading.png` |
| `font_` | 位图字体 | `font_dmg.png` |

- 单张静态图不加序号；序列帧从 `01` 开始连续编号。
- 按钮状态后缀：`_normal` / `_pressed` / `_disabled`；选中态 `_selected`。
- 图集文件名：`atlas_<分组>.png` + `atlas_<分组>.json`。

## 10. 交付检查清单（每批资源）

1. 文件名全部符合第 8 节，ID 能在配置表里对上。
2. 同一角色所有帧画布尺寸一致、锚点在脚底中心。
3. 透明背景，边缘无白边/黑边（加色特效除外）。
4. 缩到手机实际大小（例如 400px 宽预览）检查：玩家、怪、敌方子弹、宝箱一眼能分清（GDD §13.1）。
5. 九宫格写明边距；循环动画标明循环帧；障碍标明占地格。
6. 附一行说明：本批包含哪些 ID、哪些还没出。

## 11. 确认结果（美术 2026-10-11）

1. 1 格 64px、主角画布 128 × 128：确认。
2. 怪物红紫描边光：**程序用着色器加**，2px 外发光，颜色 `#D9468C`，透明度 0.6；美术图里不画。
3. 换色：先走程序色板，美术随各区域素材交色板对照表。
4. 帧数：主角跑动 8、待机 6；**普通怪移动降为 4 帧**（史莱姆、蝙蝠的弹跳由程序缩放补），攻击、死亡帧数按第 4 节。
5. 底栏格子 84px：确认。

现有首批文件保持原名，程序侧做映射；补序列帧时按配置表 ID 重出，届时删除映射。地面另补 64 × 64 瓦片。
